# The Unfinished Story

An anonymous dispatch leads to five sealed case files. Inspect evidence, recover a missing record and use your investigation journal to connect the clues.

## Play offline

Keep `index.html`, `style.css` and `script.js` together, then open `index.html` in a modern browser. No installation or build is required. Progress and the sound preference are stored in the current browser. Use the same browser and address to resume.

## Publish with Netlify Drop

1. Sign in to your free Netlify account and open [Netlify Drop](https://app.netlify.com/drop).
2. Drop the **the-unfinished-story** folder containing `index.html`. Use that folder as the upload root.
3. Open the production `https://….netlify.app` address in a private browsing window and check that the opening screen appears without a sign-in prompt. Choose a memorable site name in Netlify before printing or sharing the URL.
4. To update the game, open the existing site's **Deploys** page and use its manual deploy drop zone with the updated folder. The production URL stays the same when you deploy to the same site.

The journal, check buttons and optional sound all run in the browser. The game makes no external requests.
