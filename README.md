# The Unfinished Story

An anonymous dispatch leads to five sealed case files. Inspect locked boxes, send signals through the wall and help two travellers find a way through the dark. The investigation journal keeps track of what you discover.

## Play offline

Keep `index.html`, `style.css`, `puzzles.js` and `script.js` together, then open `index.html` in a modern browser. No installation or build is required. Progress and the sound preference are stored in the current browser. Use the same browser and address to resume.

## GitHub Pages

This repository publishes from the root of the `main` branch. Push updates there and check the Pages build under **Actions**. The static files need no build or configuration. The same folder can also be uploaded to Netlify Drop.

The redesigned puzzles start a fresh investigation for returning players and carry over their sound preference. The journal, puzzle controls and optional sound run in the browser. The game makes no external requests.
